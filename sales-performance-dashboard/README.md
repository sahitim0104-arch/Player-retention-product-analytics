# Sales Performance Dashboard — Looker Studio

## Overview

An academic sales analytics dashboard created using Looker Studio to analyze sales performance across regions, products, customers, salespeople, payment methods, and discounts.

## Tools Used

- Looker Studio
- Excel / Google Sheets

## Dashboard Analysis

- Executive Sales Overview
- Regional Performance
- Product Performance
- Customer & Salesperson Performance
- Payment Behaviour
- Discount Analysis

## Key Metrics

- Total Sales
- Total Orders
- Total Quantity
- Sales by Category
- Sales by Region
- Product Performance
- Salesperson Performance
- Top Customers
- Payment Behaviour
- Average Discount

## Project Type

Academic / Portfolio Project

This dashboard was created as part of a PGDM analytics assignment.
